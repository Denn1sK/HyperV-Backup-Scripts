# HyperV-Backup-Scripts
PowerShell-скрипты для резервного копирования виртуальных машин Hyper-V на Windows 10/11 через Export-VM. Настройка через интерактивный мастер, запуск вручную или по расписанию через Планировщик заданий. Конфиг, логи, автоматическая очистка старых бэкапов, проверка свободного места, режим dry-run.
